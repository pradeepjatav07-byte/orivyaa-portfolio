## Overview

This repository hosts my end-to-end digital marketing portfolio for **ORIVYAA · JalNest** — a self-watering planter brand taken through a complete marketing journey in one semester: website, SEO, paid ads, social media and email marketing.

The portfolio is a fully static website (HTML/CSS/JS) — no build tools or dependencies required.
